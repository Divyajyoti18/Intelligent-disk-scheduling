# Intelligent Disk Scheduling with Reinforcement Learning-Based Predictive Caching

## Overview

This project aims to develop an intelligent disk scheduling system
that combines traditional disk scheduling algorithms, predictive
caching, and reinforcement learning to improve disk I/O performance.

## Objectives

- Implement traditional disk scheduling algorithms.
- Build a disk I/O simulator.
- Generate different workload patterns.
- Implement predictive caching.
- Develop a reinforcement learning-based scheduler.
- Compare the intelligent approach with traditional algorithms.

- Pandas
